# 📚 Template SLiMS "ios"

Template untuk SLiMS versi 9.6 Bulian, terinspirasi oleh desain modern dari situs [onesearch.id](https://onesearch.id) pada tahun 2025. Berharap agar lebih banyak perpustakaan yang meng-indek-an datannya ke onesearch 

## ✨ Tentang Template

- 🔧 **Nama Template**: `ios`  
- 👨‍💻 **Author**: Erwan Setyo Budi ([erwans818@gmail.com](mailto:erwans818@gmail.com))  
- 🎯 **Dibuat untuk**: SLiMS 9.6 Bulian  
- 💡 **Inspirasi**: Tampilan dan pengalaman pengguna situs OneSearch versi 2025  

Template ini dirancang agar tampil lebih modern, bersih, dan responsif, serta memberikan pengalaman pengguna OPAC yang lebih nyaman.

## 🚀 Cara Instalasi

1. **Unduh** file template ini dari repositori GitHub.
2. **Ekstrak** folder hasil unduhan ke dalam direktori `template/` milik SLiMS.
3. **Login** sebagai Super Admin ke sistem SLiMS.
4. **Aktifkan template** melalui menu: `System → Theme`, lalu pilih `ios`.
5. **Lihat hasilnya** di halaman OPAC.![preview](https://github.com/user-attachments/assets/d454e338-1988-44aa-b34a-0bbc104d4976)
